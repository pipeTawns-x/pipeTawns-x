## 🤖 Cómo trabajo

- **Spec-driven development, no vibe coding**: primero exploro, propongo y especifico; después se escribe código.
- **Agentes de IA como equipo, yo decido**: los agentes ejecutan las tareas; yo reviso cada cambio y tomo las decisiones finales.
- **Cada proyecto corre en Docker con CI**: entornos reproducibles y pipelines con escaneo antes de merge.
- **PRs revisados antes de merge**: nada entra a `main` sin pasar por revisión.
