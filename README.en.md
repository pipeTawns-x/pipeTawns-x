## Featured project: Carni-mvp

I'm taking a real business online, with AI built in. Customers browse the store, put their order together and choose between home delivery or picking it up at the shop.

[<img src="https://raw.githubusercontent.com/pipeTawns-x/Landingpages-Carni.pwa/main/docs/screenshots/home.jpg" width="600" alt="Carni-mvp home page, deployed online">](https://pipetawns-x.github.io/Landingpages-Carni.pwa/)

- It installs on a phone like an app and still opens without a connection.
- A virtual assistant answers questions in Spanish while the customer shops.
- Accounts with roles: each person, customer or admin, sees only the information that belongs to them.
- In the admin panel I'm building a campaign module that generates voice with AI.

**Live demo:** [pipetawns-x.github.io/Landingpages-Carni.pwa](https://pipetawns-x.github.io/Landingpages-Carni.pwa/)

## How I work

- Spec-driven development, not vibe coding: first I explore, propose and specify; only then does the code get written.
- Agents execute, I decide: I review every change and make the final calls.
- Carni-mvp has a Docker environment and runs CI on GitHub Actions.
- I keep branches separated by purpose (production, coursework and testing), and big changes go through pull requests.
